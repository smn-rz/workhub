#### Sandra

  Massagebehandlingar (beauty.html, beauty.css, beauty.js)
 
  Jag har ansvarat för bokningssidan för massagebehandlingar och byggt den med HTML, CSS och JavaScript. Jag har skapat dynamiska behandlingskort med utfällbara beskrivningar, val av behandling och antal tillfällen, automatisk prisberäkning samt formulär med egen validering. Jag har även implementerat bokningsbekräftelse, återställning och responsiv design utifrån gruppens gemensamma färger och stil.
  

#### Gemensam design
Vi har arbetat med en gemensam design för att skapa ett enhetligt utseende på webbplatsen. Vi har använt gemensamma färger, typografi, navigation och knappstilar.
GitHub och samarbete
